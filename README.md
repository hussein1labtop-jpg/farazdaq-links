# موقع حسابات أساتذة معهد الفرزدق

## طريقة الرفع على GitHub Pages
1. إنشاء مستودع (Repository) جديد على GitHub، مثلاً باسم `farazdaq-links`.
2. رفع كل الملفات (index.html + README.md + logo.jpg + كل صور الأساتذة) **بجذر المستودع مباشرة** (بدون مجلدات فرعية).
3. من إعدادات المستودع Settings → Pages → اختر الفرع `main` والمجلد `/ (root)` ثم Save.
4. سيصبح الرابط بالشكل:
   `https://USERNAME.github.io/farazdaq-links/`

## طريقة إضافة صورة كل أستاذ (خطوة ضرورية)
لأن جلب الصور تلقائياً من انستغرام غير مضمون، كل صورة أستاذ تُرفع يدوياً باسم ملف محدد. الأسماء المطلوبة بالضبط:

| الأستاذ | اسم ملف الصورة |
|---|---|
| معهد الفرزدق | `fsc_2017.jpg` |
| حسين النجار | `hu_alnajjar.jpg` |
| طه حسين | `taha_alassady.jpg` |
| حيدر الحسناوي | `haider_math.jpg` |
| عبد الأمير الموسوي | `abdal_amir11.jpg` |
| أوس الجيلاوي | `aws_aljelawy.jpg` |
| حسام وساف | `hu_wassaf.jpg` |
| إيهاب العبيدي | `ihab_alabiedi.jpg` |
| خليل كامل | `n2k_y.jpg` |
| علاء المعموري | `alaa_91.jpg` |
| نبيل السيلاوي | `nabeelassilawi.jpg` |

**كيف تجيب الصورة من انستغرام:**
1. افتح حساب الأستاذ بتطبيق انستغرام أو بالمتصفح.
2. اضغط ضغطة طويلة على صورة البروفايل (الدائرة بالأعلى) → Save Image / حفظ الصورة، أو خذ لقطة شاشة وقصها دائرية.
3. غيّر اسم الملف بجهازك ليطابق الجدول فوق بالضبط (بأحرف صغيرة وبدون مسافات).
4. ارفعه لنفس مستودع GitHub بجذر المستودع (نفس مكان index.html) عبر Add file → Upload files.
5. سوّي Commit changes.

كرر هذا لكل أستاذ. إذا صورة معينة ما انرفعت أو الاسم غلط، تلقائياً تظهر شعار المعهد بدلها (fallback) بدون ما يتعطل الموقع.

## طريقة إضافة حساب جديد لاحقاً
افتح ملف `index.html`، دور على القسم المكتوب فوگه:
`قائمة الحسابات — لإضافة حساب جديد أضف سطراً هنا بنفس الشكل`

وأضف سطر جديد بنفس النمط:
```js
{ name: "الأستاذ فلان الفلاني", role: "", username: "instagram_username", photo: "flan_alfulani.jpg" },
```
ثم ارفع صورته بنفس اسم `photo` المكتوب، بجذر المستودع. احفظ (commit) والصفحة تتحدث تلقائياً بدون أي تغيير على الرابط.
