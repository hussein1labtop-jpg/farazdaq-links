# موقع حسابات أساتذة معهد الفرزدق

## طريقة الرفع على GitHub Pages
1. إنشاء مستودع (Repository) جديد على GitHub، مثلاً باسم `farazdaq-links`.
2. رفع الملفين:
   - `index.html`
   - مجلد `assets` (وبداخله `logo.jpg`)
3. من إعدادات المستودع Settings → Pages → اختر الفرع `main` والمجلد `/root` ثم Save.
4. سيصبح الرابط بالشكل:
   `https://USERNAME.github.io/farazdaq-links/`

## طريقة إضافة حساب جديد (بدون ما يتغير الرابط ولا QR)
افتح ملف `index.html`، دور على القسم المكتوب فوگه:
`قائمة الحسابات — لإضافة حساب جديد فقط أضف سطراً هنا بنفس الشكل`

وأضف سطر جديد بنفس النمط:
```js
{ name: "الأستاذ فلان الفلاني", role: "", username: "instagram_username" },
```
احفظ الملف وارفعه (commit) على نفس المستودع، والصفحة تتحدث تلقائياً بدون أي تغيير على الرابط أو رمز QR.

## ملاحظة عن صور البروفايل
الصور تنجلب تلقائياً (لحظة فتح الزائر للصفحة) من انستغرام عبر خدمة unavatar.io حسب اليوزر المكتوب،
فإذا الأستاذ غيّر صورة حسابه على انستغرام، تنحدث هي بنفسها بالموقع بلا أي تدخل. وإذا الخدمة ما گدرت
تجيب الصورة لأي سبب، تنعرض صورة شعار المعهد بدلها تلقائياً.
